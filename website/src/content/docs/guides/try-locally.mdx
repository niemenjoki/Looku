**What you get:** Looku and a small demo site running on your own computer. You browse the demo site, and the page
views appear in Looku's dashboard. Nothing is published on the internet and no real site is touched.

**Time:** about 20 minutes, most of it downloads. **You need:** a computer with Windows 10 or 11, macOS or Linux,
about 3 GB of free disk space, and an internet connection.

This uses the same Docker Compose setup as a real installation, so the commands you learn here are the ones you use
on a server later. When you are done, one command removes everything.

## Before you start

You need two programs, Docker and Git, and a terminal to type commands in.

**Open a terminal.** On Windows, open the Start menu, type `PowerShell` and open **Windows PowerShell** (or
**Terminal**). On macOS, open **Terminal** (Applications → Utilities). On Linux, open your terminal app. The commands
on this page are the same on all three, except where tabs show a difference.

**Docker** runs Looku in containers, so you do not install anything else.

<Tabs syncKey="os">
<TabItem label="Windows">

Download **Docker Desktop** from [docker.com](https://www.docker.com/products/docker-desktop/) and run the installer.
Keep the defaults (it uses WSL 2 in the background; you do not need to use WSL yourself) and restart the computer if
asked. Then start **Docker Desktop** from the Start menu, accept its terms, and wait until it says **Engine running**.
If it complains about virtualization, it must be turned on in the computer's firmware settings (BIOS or UEFI); see
[Docker's troubleshooting topics](https://docs.docker.com/desktop/troubleshoot-and-support/troubleshoot/topics/) and
search the page for "virtualization".

</TabItem>
<TabItem label="macOS">

Download **Docker Desktop** from [docker.com](https://www.docker.com/products/docker-desktop/). Choose **Apple
silicon** or **Intel** according to your Mac (Apple menu → About This Mac → Chip or Processor). Open the downloaded file, drag
Docker to Applications, start it from Applications, accept its terms, and wait until it says **Engine running**.

</TabItem>
<TabItem label="Linux">

Install **Docker Engine** by following [Docker's guide for your distribution](https://docs.docker.com/engine/install/).
Then let your user run Docker without `sudo`, and log out and back in for it to take effect:

```bash
sudo usermod -aG docker $USER
```

(Membership of the `docker` group is equivalent to administrator rights on that computer.)

</TabItem>
</Tabs>

Docker Desktop is free for personal use and for small businesses; larger companies need a paid subscription. It must
be running whenever you use Looku on Windows or macOS. Check that Docker works:

```bash
docker compose version
```

You should see `Docker Compose version v2.…`. If you see an error with `cannot connect to the Docker daemon` or
`error during connect`, Docker Desktop is not running yet.

**Git** downloads the code. Check whether you have it:

```bash
git --version
```

You should see something like `git version 2.47.1`. If the command is not found, install Git:

<Tabs syncKey="os">
<TabItem label="Windows">

Download **Git for Windows** from [git-scm.com](https://git-scm.com/downloads/win) and install it with the default
choices. Close PowerShell, open it again, and run `git --version` again.

</TabItem>
<TabItem label="macOS">

Running `git --version` offers to install the command line developer tools. Accept, wait for the installation, and run
`git --version` again.

</TabItem>
<TabItem label="Linux">

On Ubuntu and Debian: `sudo apt install git`.

</TabItem>
</Tabs>

## Start Looku

<Steps>

1. **Download the code.** This creates a folder called `looku` in the folder you are in (your home folder if you
   just opened the terminal), and moves you into its `deploy` folder, where the Docker files are:

   ```bash
   git clone https://github.com/niemenjoki/Looku.git looku
   cd looku/deploy
   ```

   You should see `Cloning into 'looku'...` and a few lines of progress. The prompt then shows that you are in the
   `deploy` folder.

2. **Create the settings file.** Looku reads its settings from a file called `.env`. Copy the example:

   ```bash
   cp .env.example .env
   ```

   Nothing is printed. Open the file in a text editor:

   <Tabs syncKey="os">
   <TabItem label="Windows">

   ```powershell
   notepad .env
   ```

   </TabItem>
   <TabItem label="macOS">

   ```bash
   open -e .env
   ```

   </TabItem>
   <TabItem label="Linux">

   ```bash
   nano .env
   ```

   </TabItem>
   </Tabs>

   Change the first setting to:

   ```
   LOOKU_DATA_DIR=looku-data
   ```

   and save the file (in nano: Ctrl+O, Enter, Ctrl+X). Leave the other lines as they are. This keeps Looku's
   database in a Docker volume, a storage area managed by Docker, instead of a folder on your computer. Databases
   do not always work reliably in folders shared from Windows or macOS into a container, and a volume is removed
   with one command when you are done. On a real server you keep `./data`, a normal folder that is easy to back up.

3. **Start Looku:**

   ```bash
   docker compose up -d --build
   ```

   The first time, Docker downloads and builds Looku, which takes a few minutes. It ends with
   `Container looku-ingest-1 Started` and `Container looku-dashboard-1 Started`. `-d` means Looku runs in the
   background, so you get the prompt back. Check it:

   ```bash
   docker compose ps
   ```

   Both `looku-ingest-1` and `looku-dashboard-1` should show `Up`. If the first command says
   `port is already allocated`, another program uses port 8788: change `LOOKU_DASHBOARD_PORT` in `.env` to, for
   example, `8789`, run the command again, and use that port instead of 8788 below.

4. **Add the demo site.** `demo` is the site id, `localhost` is the demo site's address, and the time zone decides
   when a day changes in the reports (use your own, for example `America/New_York`):

   ```bash
   docker compose run --rm ingest site:add demo --domain localhost --timezone Europe/Helsinki
   ```

   `docker compose run --rm ingest` runs one Looku command in a temporary container and removes the container
   afterwards. Docker first prints a line or two about that container (`Container looku-ingest-run-… Created`), then:

   ```
   Site demo added. Signing key (shown once):
   k8Jd2mQx7RfTn4WcZp1LvB9sHy6GaE0uYoXiN5tCw3E
   ```

   Your key is different. **Copy it now**: select it with the mouse and copy it (Ctrl+C on Windows, Cmd+C on macOS,
   Ctrl+Shift+C in most Linux terminals). You need it in
   step 7. If you lose it, `docker compose run --rm ingest site:rotate-key demo` prints a new one. The time zone can
   be changed later with `site:timezone`.

5. **Turn on two more modules,** content (reading time) and campaigns:

   ```bash
   docker compose run --rm ingest site:modules demo content,campaigns
   ```

   The last line should say `Modules of demo: perus, content, campaigns`. `perus` (basic) is always on.

6. **Set the dashboard password.** It must be at least 10 characters long:

   ```bash
   docker compose run --rm -it ingest admin:password
   ```

   It asks `New dashboard password:`. Type the password and press Enter. **Nothing appears while you type**, not even
   dots; that is on purpose. It asks only once, so type carefully. You should see
   ``Password set. Restart `looku serve` to end existing logins.`` (Nobody is logged in yet, so there is nothing to
   restart.) If you mistyped, run the command again. `-it` connects your keyboard to the container.

7. **Create the demo site's settings.** Go to the demo's folder and copy its example settings:

   ```bash
   cd ../examples/next-demo
   cp .env.example .env.local
   ```

   Open `.env.local` in the text editor as in step 2 (`notepad .env.local`, `open -e .env.local` or
   `nano .env.local`) and change it to:

   ```
   LOOKU_ENDPOINT=http://ingest:8787
   LOOKU_SITE_ID=demo
   LOOKU_SIGNING_KEY=the key you copied in step 4
   ```

   Save the file. These are the three settings every connector needs: where Looku's receiver is, which site this is,
   and the key to sign with. `ingest` is the receiver's name inside Docker: the demo will run in a container next to
   Looku and finds the receiver by that name. A real site uses the receiver's public address instead.

8. **Start the demo site.** Go back to the `looku` folder and start the demo in a container (one long line):

   ```bash
   cd ../..
   docker run --rm -it --init --name looku-demo --network looku_default -p 127.0.0.1:3000:3000 -v "${PWD}:/src:ro" node:22-bookworm-slim sh -c "cp -r /src /app && cd /app/examples/next-demo && npm install && npm run build && npm start"
   ```

   What it does: it starts a container with Node.js (`node:22-bookworm-slim`) on the same network as Looku
   (`--network looku_default`), shows it to you at port 3000 (`-p`), lets it read the `looku` folder (`-v`, read
   only), copies the code inside the container, and then installs, builds and starts the demo. Nothing is written
   to your folder, and `--rm` removes the container when it stops.

   The first time takes a few minutes. Lines starting with `npm notice` and a note about Next.js telemetry are
   normal. It is ready when you see `- Local: http://localhost:3000` and `✓ Ready in …`. The demo now runs in this
   window, so leave it open.

</Steps>

:::note[Why a production build?]
The connector sends page views only from a production build (`npm run build` and `npm start`), not from
`npm run dev`, so that your own development does not fill the statistics.
:::

## See it work

<Steps>

1. Open [http://localhost:3000](http://localhost:3000) in your browser and click through a few pages.
2. Open [http://localhost:3000/tuotteet?utm_source=news&utm_campaign=demo](http://localhost:3000/tuotteet?utm_source=news&utm_campaign=demo).
   This is a campaign link, like one you would put in a newsletter.
3. At the bottom of the demo page, select **Salli** (allow) to give consent for measuring reading time, then scroll
   the guide page and stay on it for a while.
4. Open the dashboard at [http://127.0.0.1:8788](http://127.0.0.1:8788) and log in with your password.

</Steps>

**It works if:**

- the page views appear in the dashboard, and the campaign `demo` appears among the campaigns,
- reading time appears only for pages you viewed after selecting "Salli",
- your browser's storage for `localhost:3000` has nothing from Looku (the consent choice is the demo site's own).

If the dashboard stays empty, see [No page views appear](/looku/operate/troubleshooting/#no-page-views-appear). If your
browser sends Do Not Track or Global Privacy Control (Brave does by default), Looku skips your page views on purpose:
try another browser.

## Clean up

<Steps>

1. **Stop the demo** with Ctrl+C in its window. The container is removed.

2. **Remove Looku and its data.** In the same window (you are in the `looku` folder):

   ```bash
   cd deploy
   docker compose down -v
   docker image rm looku:local node:22-bookworm-slim
   ```

   `down -v` removes the containers and the data volume; `image rm` frees the disk space used by the images.

3. **Delete the folder:**

   <Tabs syncKey="os">
   <TabItem label="Windows">

   ```powershell
   cd ~
   Remove-Item -Recurse -Force ~\looku
   ```

   </TabItem>
   <TabItem label="macOS">

   ```bash
   cd ~
   rm -rf ~/looku
   ```

   </TabItem>
   <TabItem label="Linux">

   ```bash
   cd ~
   rm -rf ~/looku
   ```

   </TabItem>
   </Tabs>

</Steps>

You can uninstall Docker Desktop too if you do not need it.
