## Is Looku for you?

Looku fits a site owner who has (or wants) a small server, such as a home server or a cheap virtual server, and whose
site runs on a server of its own: Next.js, Node.js, Express, or a static site behind Cloudflare. It does not fit a
site where you can only paste a script into the page, such as a hosted website builder.

See [What you can do with Looku](/looku/use-cases/) for seven common uses, from plain page views to shop sales.

Looku is not a cookie banner tool and does not make anything legal by itself. Read
[Privacy and the law](/looku/privacy/) before you use it.
