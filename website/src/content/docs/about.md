Looku is made by Joonas Niemenjoki, a building automation programmer from Finland.

He made it for his own small web shop, Lieromaa, to see which pages and campaigns work without sending visitors'
data to an outside analytics service. It then grew into a tool that anyone with a small server can use.

Looku is a personal project. Code, questions and bug reports: [github.com/niemenjoki](https://github.com/niemenjoki).
