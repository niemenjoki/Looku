**Mitä saat:** Lookun ja pienen demosivuston käyntiin omalle tietokoneellesi. Selaat demosivustoa, ja sivunäytöt
ilmestyvät Lookun kojelautaan. Mitään ei julkaista internetiin, eikä mihinkään oikeaan sivustoon kosketa.

**Aika:** noin 20 minuuttia, josta suurin osa on latauksia. **Tarvitset:** tietokoneen, jossa on Windows 10 tai 11,
macOS tai Linux, noin 3 Gt vapaata levytilaa ja internetyhteyden.

Kokeilu käyttää samaa Docker Compose -asennusta kuin oikea asennus, joten tässä opitut komennot ovat samoja, joita
käytät myöhemmin palvelimella. Kun olet valmis, muutama komento poistaa kaiken.

## Ennen kuin aloitat

Tarvitset kaksi ohjelmaa, Dockerin ja Gitin, sekä päätteen, johon kirjoitat komentoja.

**Avaa pääte.** Windowsissa avaa Käynnistä-valikko, kirjoita `PowerShell` ja avaa **Windows PowerShell** (tai
**Pääte**). macOS:ssä avaa **Pääte** (Ohjelmat → Lisäohjelmat). Linuxissa avaa pääteohjelmasi. Tämän sivun komennot
ovat samat kaikissa kolmessa, paitsi kun välilehdet näyttävät eron.

**Docker** ajaa Lookua konteissa, joten muuta ei tarvitse asentaa.

<Tabs syncKey="os">
<TabItem label="Windows">

Lataa **Docker Desktop** osoitteesta [docker.com](https://www.docker.com/products/docker-desktop/) ja aja
asennusohjelma. Pidä oletusvalinnat (se käyttää taustalla WSL 2:ta; sinun ei tarvitse käyttää WSL:ää itse) ja
käynnistä tietokone uudelleen, jos sitä pyydetään. Käynnistä sitten **Docker Desktop** Käynnistä-valikosta, hyväksy
sen ehdot ja odota, kunnes siinä lukee **Engine running**. Jos se valittaa virtualisoinnista, virtualisointi pitää
kytkeä päälle tietokoneen laiteohjelmiston asetuksista (BIOS tai UEFI); katso
[Dockerin vianetsintäohjeet](https://docs.docker.com/desktop/troubleshoot-and-support/troubleshoot/topics/) ja hae
sivulta sanaa "virtualization".

</TabItem>
<TabItem label="macOS">

Lataa **Docker Desktop** osoitteesta [docker.com](https://www.docker.com/products/docker-desktop/). Valitse **Apple
silicon** tai **Intel** Macisi mukaan (Omena-valikko → Tietoja tästä Macista → Siru tai Suoritin). Avaa ladattu
tiedosto, vedä Docker Ohjelmat-kansioon, käynnistä se sieltä, hyväksy sen ehdot ja odota, kunnes siinä lukee
**Engine running**.

</TabItem>
<TabItem label="Linux">

Asenna **Docker Engine** [Dockerin jakelukohtaisen ohjeen](https://docs.docker.com/engine/install/) mukaan. Anna
sitten käyttäjällesi oikeus ajaa Dockeria ilman `sudo`a, ja kirjaudu ulos ja takaisin sisään, jotta muutos tulee
voimaan:

```bash
sudo usermod -aG docker $USER
```

(Jäsenyys `docker`-ryhmässä vastaa ylläpitäjän oikeuksia kyseisellä tietokoneella.)

</TabItem>
</Tabs>

Docker Desktop on ilmainen henkilökohtaiseen käyttöön ja pienyrityksille; suuremmat yritykset tarvitsevat maksullisen
tilauksen. Sen pitää olla käynnissä aina, kun käytät Lookua Windowsissa tai macOS:ssä. Tarkista, että Docker toimii:

```bash
docker compose version
```

Näet tekstin `Docker Compose version v2.…` tai suuremman numeron. Jos näet sen sijaan virheen:

- `cannot connect to the Docker daemon` tai `error during connect`: Windowsissa ja macOS:ssä Docker Desktop ei ole
  vielä käynnissä; Linuxissa käynnistä Docker komennolla `sudo systemctl start docker`.
- `permission denied` (Linux): et ole kirjautunut ulos ja takaisin sisään `usermod`-komennon jälkeen. Tee se tai
  käynnistä tietokone uudelleen.
- `'compose' is not a docker command` (Linux): Docker on asennettu jakelun omasta paketista. Asenna se sen sijaan
  yllä linkitetyn Dockerin ohjeen mukaan.

**Git** lataa koodin. Tarkista, onko se asennettu:

```bash
git --version
```

Näet esimerkiksi `git version 2.47.1`. Jos komentoa ei löydy, asenna Git:

<Tabs syncKey="os">
<TabItem label="Windows">

Lataa **Git for Windows** osoitteesta [git-scm.com](https://git-scm.com/downloads/win) ja asenna se oletusvalinnoilla.
Sulje PowerShell, avaa se uudelleen ja aja `git --version` uudelleen.

</TabItem>
<TabItem label="macOS">

`git --version` tarjoutuu asentamaan komentorivin kehitystyökalut. Hyväksy, odota asennuksen valmistumista ja aja
`git --version` uudelleen.

</TabItem>
<TabItem label="Linux">

Ubuntussa ja Debianissa: `sudo apt install git`. Fedorassa: `sudo dnf install git`. Muissakin jakeluissa on
`git`-paketti.

</TabItem>
</Tabs>

## Käynnistä Looku

<Steps>

1. **Lataa koodi.** Tämä luo kansion `looku` siihen kansioon, jossa olet (kotikansioosi, jos avasit päätteen juuri),
   ja siirtää sinut sen `deploy`-kansioon, jossa Docker-tiedostot ovat:

   ```bash
   git clone https://github.com/niemenjoki/Looku.git looku
   cd looku/deploy
   ```

   Näet tekstin `Cloning into 'looku'...` ja muutaman edistymisrivin. Kehote näyttää sen jälkeen, että olet
   `deploy`-kansiossa.

2. **Luo asetustiedosto.** Looku lukee asetuksensa tiedostosta `.env`. Kopioi esimerkki:

   ```bash
   cp .env.example .env
   ```

   Mitään ei tulostu. Avaa tiedosto tekstieditorissa:

   <Tabs syncKey="os">
   <TabItem label="Windows">

   ```powershell
   notepad .env
   ```

   </TabItem>
   <TabItem label="macOS">

   ```bash
   open -e .env
   ```

   </TabItem>
   <TabItem label="Linux">

   ```bash
   nano .env
   ```

   </TabItem>
   </Tabs>

   Etsi rivi, joka alkaa `LOOKU_DATA_DIR=` (`#`-merkillä alkavat rivit ovat kommentteja), ja muuta se muotoon:

   ```
   LOOKU_DATA_DIR=looku-data
   ```

   ja tallenna tiedosto (nanossa: Ctrl+O, Enter, Ctrl+X). Jätä muut rivit ennalleen. Näin Lookun tietokanta on
   Docker-taltiossa, Dockerin hallitsemassa tallennustilassa, eikä tietokoneesi kansiossa. Tietokannat eivät aina
   toimi luotettavasti kansioissa, jotka jaetaan Windowsista tai macOS:stä konttiin, ja taltion saa poistettua yhdellä
   komennolla, kun olet valmis. Oikealla palvelimella pidät asetuksen `./data`: tavallisen kansion, joka on helppo
   varmuuskopioida.

3. **Käynnistä Looku:**

   ```bash
   docker compose up -d --build
   ```

   Ensimmäisellä kerralla Docker lataa ja rakentaa Lookun, mikä kestää muutaman minuutin. Lopussa näkyvät rivit
   `Container looku-ingest-1 Started` ja `Container looku-dashboard-1 Started`. `-d` tarkoittaa, että Looku jää
   käyntiin taustalle ja saat kehotteen takaisin. Tarkista tilanne:

   ```bash
   docker compose ps
   ```

   Sekä `looku-ingest-1` että `looku-dashboard-1` näyttävät tilan `Up` (ensimmäisen minuutin ajan siinä voi lukea
   myös `health: starting`). Jos ensimmäinen komento sanoo
   `port is already allocated`, jokin muu ohjelma käyttää porttia 8788: muuta `.env`-tiedostossa
   `LOOKU_DASHBOARD_PORT` esimerkiksi arvoon `8789`, aja komento uudelleen ja käytä alla sitä porttia 8788:n sijaan.

4. **Lisää demosivusto.** `demo` on sivuston tunnus, `localhost` on demosivuston osoite, ja aikavyöhyke ratkaisee,
   milloin päivä vaihtuu raporteissa (käytä omaasi, esimerkiksi `Europe/Helsinki`):

   ```bash
   docker compose run --rm ingest site:add demo --domain localhost --timezone Europe/Helsinki
   ```

   `docker compose run --rm ingest` ajaa yhden Lookun komennon väliaikaisessa kontissa ja poistaa kontin sen jälkeen.
   Docker tulostaa ensin rivin tai kaksi tästä kontista (`Container looku-ingest-run-… Created`), sitten:

   ```
   Site demo added. Signing key (shown once):
   k8Jd2mQx7RfTn4WcZp1LvB9sHy6GaE0uYoXiN5tCw3E
   ```

   Sinun avaimesi on eri. **Kopioi se nyt**: valitse se hiirellä ja kopioi (Windowsissa Ctrl+C, macOS:ssä Cmd+C,
   useimmissa Linuxin päätteissä Ctrl+Shift+C). Tarvitset sitä vaiheessa 7. Jos se katoaa,
   `docker compose run --rm ingest site:rotate-key demo` tulostaa uuden. Aikavyöhykkeen voi vaihtaa myöhemmin
   komennolla `site:timezone`.

5. **Ota käyttöön kaksi moduulia lisää,** sisältö (lukuaika) ja kampanjat:

   ```bash
   docker compose run --rm ingest site:modules demo content,campaigns
   ```

   Viimeisellä rivillä lukee `Modules of demo: perus, content, campaigns`. `perus` on aina päällä.

6. **Aseta kojelaudan salasana.** Sen pitää olla vähintään 10 merkkiä pitkä:

   ```bash
   docker compose run --rm -it ingest admin:password
   ```

   Komento kysyy `New dashboard password:`. Kirjoita salasana ja paina Enter. **Kirjoittaessa ruudulle ei tule
   mitään**, ei edes pisteitä; se on tarkoituksellista. Salasana kysytään vain kerran, joten kirjoita huolellisesti.
   Näet tekstin ``Password set. Restart `looku serve` to end existing logins.`` (Kukaan ei ole vielä kirjautunut, joten
   mitään ei tarvitse käynnistää uudelleen.) Jos kirjoitit väärin, aja komento uudelleen. `-it` yhdistää
   näppäimistösi konttiin.

7. **Luo demosivuston asetukset.** Siirry demon kansioon ja kopioi sen esimerkkiasetukset:

   ```bash
   cd ../examples/next-demo
   cp .env.example .env.local
   ```

   Avaa `.env.local` tekstieditorissa kuten vaiheessa 2 (`notepad .env.local`, `open -e .env.local` tai
   `nano .env.local`), poista kaikki sen sisältö ja kirjoita tilalle nämä kolme riviä niin, että
   `LOOKU_SIGNING_KEY=`-kohdan perässä on oma avaimesi:

   ```
   LOOKU_ENDPOINT=http://ingest:8787
   LOOKU_SITE_ID=demo
   LOOKU_SIGNING_KEY=LIITÄ-AVAIMESI-TÄHÄN
   ```

   Ei välilyöntejä `=`-merkin ympärille eikä lainausmerkkejä. Tallenna tiedosto. Nämä ovat kolme asetusta, jotka jokainen liitin tarvitsee: missä Lookun vastaanotin on, mikä
   sivusto tämä on ja millä avaimella allekirjoitetaan. `ingest` on vastaanottimen nimi Dockerin sisällä: demo ajetaan
   kontissa Lookun vieressä, ja se löytää vastaanottimen tällä nimellä. Oikea sivusto käyttää sen sijaan
   vastaanottimen julkista osoitetta.

8. **Käynnistä demosivusto.** Palaa `looku`-kansioon ja käynnistä demo kontissa (yksi pitkä rivi):

   ```bash
   cd ../..
   docker run --rm -it --init --name looku-demo --network looku_default -p 127.0.0.1:3000:3000 -v "${PWD}:/src:ro" node:22-bookworm-slim sh -c "cp -r /src /app && cd /app/examples/next-demo && npm install && npm run build && npm start"
   ```

   Mitä se tekee: se käynnistää Node.js-kontin (`node:22-bookworm-slim`) samaan verkkoon Lookun kanssa
   (`--network looku_default`), näyttää sen sinulle portissa 3000 (`-p`), antaa sen lukea `looku`-kansiota (`-v`,
   vain luku), kopioi koodin kontin sisälle ja sitten asentaa, rakentaa ja käynnistää demon. Kansioosi ei kirjoiteta
   mitään, ja `--rm` poistaa kontin, kun se pysähtyy.

   Ensimmäinen kerta kestää muutaman minuutin. `npm notice` -alkuiset rivit ja huomautus Next.js:n telemetriasta
   ovat normaaleja. Demo on valmis, kun näet rivit `- Local: http://localhost:3000` ja `✓ Ready in …`. Demo pyörii nyt
   tässä ikkunassa, joten jätä se auki.

</Steps>

:::note[Miksi tuotantoversio?]
Liitin lähettää sivunäyttöjä vain tuotantoversiosta (`npm run build` ja `npm start`), ei komennosta
`npm run dev`, jotta oma kehitystyösi ei täytä tilastoja.
:::

## Katso, että se toimii

<Steps>

1. Avaa selaimessa **yksityinen ikkuna** (Chromessa ja Edgessä Ctrl+Shift+N, Firefoxissa Ctrl+Shift+P, Safarissa
   Cmd+Shift+N) ja avaa siinä
   [http://localhost:3000/tuotteet?utm_source=news&utm_campaign=demo](http://localhost:3000/tuotteet?utm_source=news&utm_campaign=demo).
   Tämä on kampanjalinkki, jollaisen laittaisit esimerkiksi uutiskirjeeseen. Looku laskee käynnin sille kampanjalle,
   josta käynti alkoi, joten avaa tämä linkki ensin.
2. Klikkaile demosivuston muutamaa sivua.
3. Valitse demosivun alareunasta **Salli**, jolloin annat suostumuksen lukuajan mittaamiseen. Vieritä sitten
   oppaat-sivua ja viivy sillä hetki.
4. Avaa kojelauta osoitteessa [http://127.0.0.1:8788](http://127.0.0.1:8788) ja kirjaudu salasanallasi.

</Steps>

**Toimii, jos:**

- kojelaudan etusivu näyttää sivunäyttösi (valitse sivusto `demo` ja tämä päivä, jos se kysyy),
- **Kampanjat**-raportissa näkyy kampanja `demo` ja yksi käynti,
- **Lukuaika ja vieritys** -raportissa on tietoja vain sivuista, joita katsoit sen jälkeen, kun valitsit "Salli"
  (siihen voi mennä minuutti).

Jos kojelauta pysyy tyhjänä:

- Katso demon ikkunaa: siellä näkyvä virhe kertoo yleensä ongelman.
- Tarkista, että `.env.local`-tiedoston avain on täsmälleen vaiheen 4 avain (tai `site:rotate-key`-komennon antama,
  joka korvaa sen). Kun olet muuttanut `.env.local`-tiedostoa, pysäytä demo painamalla Ctrl+C ja aja vaiheen 8
  `docker run` -komento uudelleen.
- Jos selaimesi lähettää Do Not Track- tai Global Privacy Control -signaalin (Brave tekee niin oletuksena), Looku
  ohittaa sivunäyttösi tarkoituksella: kokeile toisella selaimella.
- Katso vastaanottimen lokia `deploy`-kansiossa: `docker compose logs ingest`.

## Siivoa jälkesi

<Steps>

1. **Pysäytä demo** painamalla Ctrl+C sen ikkunassa. Kontti poistuu.

2. **Poista Looku ja sen tiedot.** Samassa ikkunassa (olet `looku`-kansiossa):

   ```bash
   cd deploy
   docker compose down -v
   docker image rm looku:local node:22-bookworm-slim
   ```

   `down -v` poistaa kontit ja tietotaltion; `image rm` vapauttaa levytilan, jota levykuvat käyttävät. Jos käytät
   `node:22-bookworm-slim`-levykuvaa muuhunkin, jätä se pois komennosta.

3. **Poista kansio:**

   <Tabs syncKey="os">
   <TabItem label="Windows">

   ```powershell
   cd ~
   Remove-Item -Recurse -Force ~\looku
   ```

   </TabItem>
   <TabItem label="macOS">

   ```bash
   cd ~
   rm -rf ~/looku
   ```

   </TabItem>
   <TabItem label="Linux">

   ```bash
   cd ~
   rm -rf ~/looku
   ```

   </TabItem>
   </Tabs>

   Jos latasit koodin muualle kuin kotikansioosi, poista sen sijaan se `looku`-kansio.

</Steps>

Voit poistaa myös Docker Desktopin, jos et tarvitse sitä.

## Seuraavaksi

Valitse oikea asennustapa sivulla [Aloita tästä](/looku/fi/start-here/#valitse-asennustapa). Asennusoppaat on
kirjoitettu Linux-palvelimelle: kotipalvelimelle, Raspberry Pille tai VPS:lle. Windows- tai Mac-tietokone sopii
Lookun kokeiluun, mutta oppaat eivät käsittele sitä palvelimena, koska pöytäkone menee lepotilaan, käynnistyy
uudelleen päivitysten vuoksi, ja Docker Desktop käynnistyy vasta, kun joku kirjautuu sisään.
